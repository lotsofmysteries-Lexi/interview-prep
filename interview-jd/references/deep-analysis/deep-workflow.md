# 深档工作流：深度岗位与公司分析

> 来源：job-analyzer V2.2 融入（2026-10）。核心方法论：不分析 JD 写了什么，拆解岗位本质；不做关键词连连看，基于工作偏好与人格特质匹配。
> 配套框架：`analysis-framework.md`（JD 信号解码 + T01-T15 岗位类型框架）、`gallup-framework.md`、`gallup-profile-guide.md`、`hr-response-templates.md`。

## 适用场景

| 用户意图 | 示例 |
|---------|------|
| 投递决策 | "这家公司值不值得去""深度分析这家公司" |
| 岗位本质 | "这个岗位到底是干什么的""JD 背后在招什么样的人" |
| 备战面试 | "帮我准备 XX 公司的面试""这家公司会怎么考察我" |

快档（`jd-match-rules.md`）结束后用户表达上述意图时，通过 JD-CP-02 升级进入本流程。

## Phase 0: 启动确认（JD-CP-02，never）

深档成本：联网双子 Agent 检索、约 3-5 分钟、约 100K token。必须先确认再启动。

确认卡内容：
- 成本声明（联网检索 / 时长 / token 量级）
- A 选项：完整深档 / 仅公司分析（跳过人格匹配章节）/ 不用了
- 同公司增量提示：若 `outputs/jd-match/<公司-岗位>/company-analysis.md` 已存在，声明将只做增量更新

## Phase 1: 信息检索（双子 Agent）

| 子 Agent | 检索范围 | 调用上限 |
|----------|---------|---------|
| A 公司基本面 | 官网+产品+融资+新闻+管理层+招投标（硬信息） | ≤15 次 |
| B 人与文化 | 员工体验+面经+脉脉/看准+知乎+行业口碑（软信息） | ≤10 次 |

成本控制协议：
- 单次深档总预算 ≤200K token
- 子 Agent 返回结构化结果（表格优先），减少主流程重组成本
- 同公司增量复用：company-analysis.md 已存在时，仅检索"上次分析之后的新变化"，不重跑全量

## Phase 2: 侧写加载

读取 `interview-vault/profile/work-style.yaml`：

- 存在 → 加载 L1/L2/L3 三层，进入 Phase 3
- 不存在 → 按 `gallup-profile-guide.md` 首次引导（5 个核心问题，归入 JD-CP-03 形式），生成初始 L1 后继续

## Phase 3: 分析与报告生成

8 章输出结构（`analysis-framework.md` 提供逐章框架）：

1. 核心结论（适配度一句话判断 + 三条关键依据）
2. 公司战略定位与业务全景（含技术栈与生态位）
3. 岗位深度拆解（JD 三模式判定 A 模糊/B 清晰/C 扩池 + JD 信号→公司 AI 规划反推）
4. 人格-岗位匹配（work-style 四领域 vs 岗位需求，张力点=能量消耗点标注）
5. 能力迁移性（vault full-card 证据 × Know-how 迁移矩阵）
6. 风险（公司风险速查 + 岗位风险）
7. HR 话术（第一句话说什么、如何争取面试，参考 `hr-response-templates.md`）
8. 侧写问题（为 Phase 5 预选 2-3 个渐进式问题）

写作纪律：适配度确认 + 面试高光展示是最高价值产出，报告导向"拿 offer"而非研究报告。

## Phase 4: 存档

```
interview-vault/outputs/jd-match/<公司-岗位>/
└── company-analysis.md   # 固定文件名，前端右栏"公司分析原文"依赖此契约
```

- 报告头部写 metadata：分析日期、JD 三模式、整体适配度
- 增量更新时保留原 metadata 的历史字段（`updates:` 列表）

## Phase 5: 校准反馈 + 侧写提问（JD-CP-03，user_explicit）

存档后一次交互完成两件事：

1. **反馈问句**："以上分析里，哪些地方你觉得说得准？哪些跟你的实际情况不太一样？"
   - 校准处理按 `gallup-profile-guide.md` 的规则表执行（置信度增减、偏差区标记）
2. **侧写 2-3 问**：从 30 条题库中选与本次岗位类型最相关的、优先未问过的

回答处理三步规范（8.1，禁止只回"已记录"）：
1. 意图识别：坚定选择 / 条件性选择（带顾虑）/ 犹豫需澄清
2. 简要分析：2-3 句话说明选择含义与对适配度的影响
3. 决策关联：关联报告中的具体风险点或机会点（如"你说的权限顾虑正对应风险提示第 X 点，面试可用 Q5 间接探查"）

约束：回应 3-5 句话内；不评判对错；回答写入 work-style.yaml 对应维度 + 更新日志。

## 联动其他 skill

- 第 5 章能力迁移性 → interview-resume 业务价值链路取材
- 第 7 章 HR 话术 + 第 3 章岗位本质 → interview-qa 演练第三源（qa-db 命中 × full-card 事实 × 深档洞察）
- 风险与 KPI 推断 → interview-mock 模拟考察点
- 缺口清单 → interview-mock 重点考察区域（与快档共享）
