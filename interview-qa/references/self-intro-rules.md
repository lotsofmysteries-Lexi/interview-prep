# 自我介绍生成规则

## 目标

生成面试开场的自我介绍。输出 3 分钟版（主干叙事）+ 1 分钟精简版。

## 数据来源

| 来源 | 提供什么 |
|------|---------|
| profile/master.md | 年限、行业主线、学历 |
| 跨项目 evidence | 能力标签 + 证据 |
| 跨项目 metrics | 代表性成果数据 |
| industry_thread | 职业主线 |
| 各项目 skeleton | 项目定位和角色 |

## 结构

### 3 分钟版（约 500-600 字）

```
开场定位（30秒）
  "我叫XX，XX年XX行业产品经理经验，其中XX年聚焦AI产品落地。"
  "我的核心优势在于[能力主线]。"

职业主线（60秒）
  "我的职业路径是从XX开始，[行业转型/深耕叙事]..."
  "在这个过程中，我沉淀了[方法论/核心能力]。"

代表项目（60秒）
  "举个最有代表性的项目——[项目名]，核心是[一句话定位]。"
  "我在这个项目中[角色和贡献]，最终[核心成果]。"

为什么应聘（30秒）
  "我对[目标岗位/公司]感兴趣，是因为[匹配理由]。"
  "我相信我在[能力/经验]方面的积累，能够[价值主张]。"
```

### 1 分钟版（约 180-200 字）

```
"我叫XX，XX年XX行业产品经理经验，聚焦AI产品落地。"
"核心经历是[最有代表性的1个项目，一句话讲完]，[核心成果]。"
"我擅长[2个核心能力]，期望在[目标方向]继续深耕。"
```

## 用户参与

自我介绍需要用户选择强调方向：

```
你的自我介绍可以从以下几个角度强调，你倾向哪个？

A. 技术深度：突出对 AI 技术栈的理解和技术选型能力
B. 业务理解：突出对行业场景的深度理解和 ROI 思维
C. 行业经验：突出在 XX 行业的长期积累和行业认知
D. 综合型：均衡展示以上各方面

你也可以自己说想强调什么。
```

## 写作要求

| 维度 | 要求 |
|------|------|
| 自然口语 | 能直接说出来，不像在念稿 |
| 开头抓人 | 第一句就让面试官知道你是谁、你做什么 |
| 有记忆点 | 至少有 1 个让面试官记住你的具体细节 |
| 引导追问 | 埋 1-2 个追问钩子（提到但不展开的点，引导面试官追问） |
| 与简历一致 | 提到的项目和数据必须与简历一致 |
| 不背书感 | 不用"本人""综上所述"等书面语 |

## 禁止清单

- "我是一个热爱学习的人"
- "我具有良好的沟通能力和团队协作精神"
- "我对 AI 充满热情"
- 任何没有具体事实支撑的自我评价
