# Phase 0: 建档（一次性）

## 目标

通过对话式采集，建立用户个人画像，并基于画像生成项目整体蓝图（项目数量、时间线分布、技术递进、行业线索）。

**本阶段只做一次**。后续所有项目生成、简历输出、面试模拟都基于此画像。

---

## 交互流程

### Step 1: 基础信息采集

逐步对话采集，不要一次性抛出所有问题。按以下顺序：

**第一轮（核心信息）**：

```
请告诉我你的基本情况：

1. 工作年限：总共工作了几年？其中跟 AI/大模型相关的工作有几年？
2. 学历：学校、专业、学历层次（本科/硕士/博士）
3. 行业背景：过去在什么行业工作？（可以有多段）
4. 目标岗位：接下来想找什么岗位？有 JD 的话可以发给我
```

**第二轮（素材和模式）**：

```
5. 已有素材：有没有旧简历、PRD、项目文档等材料？有的话直接发给我
6. 项目交付模式：你过去做 AI 项目时，是纯自研、部分外包、还是跟服务商合作？
   （这个只影响项目故事中"谁执行开发"的描述，你对方案设计的深度参与不受影响）
```

### Step 2: 信息确认与补全

采集完成后，向用户确认关键信息：

```
确认一下采集到的信息：

基本信息
  总工作年限：X年
  AI 相关年限：X年（从 YYYY 年开始）
  学历：XX大学 / XX专业 / 硕士
  行业背景：XX行业 X年 → XX行业 X年
  目标岗位：AI 产品经理
  交付模式：部分外包

有没有需要修改的？
```

**补全规则**：
- 如果用户没提供 AI 年限，根据行业和时间推算，然后确认
- 如果行业背景有多段，确认主线行业
- 如果交付模式用户不确定，说明各选项含义后让用户选

### Step 3: 系统派生计算

基于采集信息，自动计算以下字段（参见 `calibration-rules.md`）：

```yaml
writing_system: [校招 / 社招0-5年 / 社招5年+]
project_count_suggestion: [建议项目数]
role_baseline: [叙事视角基调]
industry_thread: [行业主线]
```

**边界处理**：
- 工作年限 4.5-5.5年：向用户确认偏向"独立负责"还是"端到端+方法论"
- 无全职经历但有丰富实习：确认走校招还是社招体系

### Step 4: 输出项目整体蓝图

```
─────────────────────────────────────────
个人画像摘要
  工作年限：X年（产品经理），AI相关：X年
  行业：XX → XX
  交付模式：XX
  写作体系：社招0-5年
  角色基调：[叙事视角基调]

项目规划（建议 N 个项目）
  项目1  YYYY下半年  [技术时代]    角色：[起始]→[终点]
  项目2  YYYY       [技术时代]    角色：[定位]
  项目3  YYYY-至今   [技术时代]    角色：[定位]

  行业线索：[行业]的 AI 落地
  技术递进：[技术A] → [技术B] → [技术C]（趋势递进，非硬规则）
  一致性备注：[跨项目一致性初步说明]
─────────────────────────────────────────
```

**蓝图生成规则**：
- 项目时间段基于 AI 年限自动分配，确保不重叠
- 技术栈按时间线→技术栈匹配表自动匹配
- 角色按年限→叙事视角表自动设定，体现成长趋势
- 行业线索从用户的行业背景提取主线

### Step 5: 用户确认蓝图

```
这是根据你的情况生成的项目规划蓝图。你可以调整：

- 项目数量（增减）
- 时间分布
- 想做的行业/场景方向
- 任何你觉得不对的地方

确认后我们开始逐个项目的场景选择。
```

用户确认后，将画像和蓝图存入 vault：

```
interview-vault/profile/master.md
```

## 已有素材处理

如果用户上传了素材（旧简历、PRD、项目文档等）：

1. **提取摘要**：自动读取并生成结构化摘要
2. **标记种子**：识别可作为项目生成种子的信息（行业、技术栈、角色、成果数据）
3. **存储原文**：保留原文供后续 Phase 1 场景推荐参考
4. **不直接复制**：素材作为输入参考，不直接搬运到项目档案中——所有内容需要经过推演重建

---

## 质量检查点

Phase 0 完成前，系统内部检查：

| 检查项 | 标准 |
|--------|------|
| 核心字段完整 | 年限、学历、行业、目标岗位、交付模式均已填 |
| 写作体系确定 | 已明确是校招/社招0-5年/社招5年+ |
| 蓝图合理性 | 项目数量与年限匹配，时间线不冲突 |
| 技术栈匹配 | 蓝图中的技术时代与时间线一致 |
| 用户已确认 | 蓝图经用户确认或修改后确认 |
