### 素材2：AI视觉质检项目验收报告（供应商出品）

```
=========================================
XX汽车零部件集团有限公司
AI视觉质检系统项目验收报告
=========================================

项目编号：DZ-2025-AI-001
项目名称：冲压件表面缺陷AI视觉检测系统
甲方：XX汽车零部件集团有限公司 数智化部
乙方：南京xx视觉科技有限公司
验收日期：2026年3月

一、项目背景

XX集团年产冲压件约500万件，原有质检方式为人工目视检查，存在以下问题：
- 漏检率约8-12%（人工疲劳导致，尤其夜班）
- 检测效率低：单件检测耗时约15-20秒
- 质量追溯困难：缺陷数据无法结构化留存
- 用工成本逐年上升：质检岗位年流动率约35%

集团数智化部于2025年Q1启动AI视觉质检项目立项，经供应商比选后于2025年4月与我司签订合作协议。

二、项目范围

2.1 检测对象
- 冲压件A类（车门内板）：5种缺陷类型
- 冲压件B类（发动机罩内板）：4种缺陷类型
- 缺陷类型包括：裂纹、划伤、凹坑、褶皱、毛刺

2.2 系统组成
- 硬件：工业相机×4（海康MV-CE200-10GC）、光源×4、工控机×2、显示终端×2
- 软件：缺陷检测算法、MES系统对接模块、数据看板

2.3 不在范围内
- 焊接件检测（二期规划）
- 与ERP系统的深度集成

三、需求与方案（甲方主导设计）

3.1 核心需求（甲方数智化部提出）
- 在线实时检测，不影响产线节拍（≤3秒/件）
- 缺陷检出率≥95%（以人工复检为基准）
- 误检率≤3%（避免过多停线误报）
- 支持缺陷分类和严重等级判定
- 检测结果实时推送至MES系统
- 支持缺陷图片和数据的结构化存储，用于质量追溯

3.2 技术方案
- 检测算法：YOLOv8 + 自研后处理规则
- 训练数据：甲方提供的历史缺陷样本12000张 + 现场采集8000张
- 标注：甲方质检专家参与标注规范定义，乙方执行标注
- 部署：边缘计算（工控机本地推理），延迟≤500ms
- 通信：MQTT协议与MES系统对接

3.3 方案评审记录
- 2025年4月15日：方案初审（甲方提出需增加边缘侧模型热更新能力）
- 2025年5月10日：方案二审通过
- 2025年6月：POC验证通过（在A类件产线试运行2周，检出率92%）
- POC后调整：增加光源角度优化，检出率提升至96%

四、实施过程

4.1 时间线
| 阶段 | 时间 | 内容 |
|------|------|------|
| 需求确认 | 2025.04 | 甲方出需求文档，乙方出技术方案 |
| POC验证 | 2025.05-06 | A类件产线试运行 |
| 数据采集标注 | 2025.06-08 | 20000张图片采集+标注 |
| 模型训练 | 2025.08-09 | 3轮训练迭代 |
| 系统集成 | 2025.09-10 | 硬件安装+软件部署+MES对接 |
| 试运行 | 2025.10-12 | A+B类件全产线试运行 |
| 正式验收 | 2026.01-03 | 验收测试+整改+终验 |

4.2 关键里程碑
- 数据标注：甲方3名质检专家参与标注规范定义（缺陷分类标准、边界case定义）；乙方5人标注团队执行，标注一致性Kappa=0.82
- 模型迭代：第一轮检出率92% → 第二轮增加数据增强后95% → 第三轮优化后处理规则达到97%
- MES对接：甲方IT部门配合，完成检测结果→工单→追溯链路的全流程打通

五、验收测试结果

5.1 功能验收

| 验收项 | 验收标准 | 实测结果 | 是否通过 |
|--------|---------|---------|---------|
| 检测速度 | ≤3秒/件 | 1.8秒/件 | ✅ |
| 缺陷检出率 | ≥95% | A类97.2%，B类95.8% | ✅ |
| 误检率 | ≤3% | A类1.5%，B类2.1% | ✅ |
| 缺陷分类准确率 | ≥90% | 92.5% | ✅ |
| MES对接 | 实时推送 | 延迟<1秒 | ✅ |
| 数据存储 | 图片+结构化 | 完整记录 | ✅ |
| 系统可用性 | ≥99% | 99.6%（试运行3个月） | ✅ |

5.2 性能测试
- 连续运行稳定性：72小时不间断测试，无宕机
- 极端情况：油污/反光/遮挡场景测试，检出率降至89%（已知限制）

六、项目成果

6.1 量化成果
- 缺陷检出率：人工8-12%漏检 → AI 2.8-4.2%漏检（降低约65%）
- 检测效率：15-20秒/件 → 1.8秒/件（提升约10倍）
- 人力节省：替代了2条产线4个质检工位（约12人/3班），年节省人力成本约96万元
- 质量追溯：缺陷数据100%结构化存储，支持按批次/时间/缺陷类型追溯

6.2 待优化项
- 极端光照条件下检出率有下降
- B类件的褶皱类缺陷误检率偏高（2.8%）
- 模型热更新功能尚未上线（二期规划）

七、甲方验收意见

本项目整体达到验收标准，同意验收通过。建议在二期项目中：
1. 扩展至焊接件检测
2. 增加缺陷趋势分析和预警功能
3. 优化极端条件下的检测稳定性

甲方项目负责人（签字）：陈建国
日期：2026年3月15日
```
