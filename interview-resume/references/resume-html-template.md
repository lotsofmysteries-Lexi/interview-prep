# 简历 HTML 排版规格

## 基本要求

- 全内联 CSS，零外部依赖
- A4 纸张规格（210mm × 297mm），使用 @page 规则
- 自适应排版，浏览器打印/导出 PDF 时无多余边距
- 严格 2 页封顶

## 页面设置

```css
@page {
  size: A4;
  margin: 0;
}

body {
  width: 210mm;
  margin: 0 auto;
  padding: 15-20mm;
  font-family: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
  color: #333;
  line-height: 1.4-1.5;
}
```

## 字体层级

| 元素 | 字号 | 字重 |
|------|------|------|
| 姓名 | 22-26px | Bold |
| 模块标题 | 14-15px | Bold + 主色 |
| 公司名/职位 | 14-15px（公司），12.5px（职位） | Bold |
| 项目名 | 13px | Bold |
| 正文 | 12-13px | Normal |
| 联系方式/日期 | 12px | Normal |

英文/数字字体栈：`'Helvetica Neue', Arial, sans-serif`

## 配色方案

```
主色：#1B3A5C（深蓝）或 #2D3436（深灰）
辅助色：#F5F6FA（浅灰背景）
正文色：#333333
次要文字：#666666
分隔线：#E0E0E0
```

全文不超过 3 种颜色。

## 模块顺序

1. **头部**：姓名 + 联系方式（电话 / 邮箱 / 所在地 / 工作年限）
2. **个人简介**（社招专属，校招无此模块）
3. **教育经历**
4. **工作经历**（项目经验合并进工作经历，作为子条目）
5. **专业技能**

## 头部规则

**保留**：姓名、电话、邮箱、所在地、工作年限
**不出现**：求职意向、期望薪资、年龄、在职状态、性别、照片

布局：
- 姓名大号主色字 + 底部 2-3px 主色粗分隔线
- 联系方式靠右对齐小字，用分隔符（|）隔开
- 可分两行：第一行电话/邮箱，第二行所在地/工作年限

## 模块标题样式

```
主色文字 + 左侧短色条(3px) + 右侧延伸细线（flex 布局）
```

## 工作经历排版

- 多家公司按**倒序**排列（最近的最前）
- 同一公司内项目也按倒序

```
公司名 + 职位（左，加粗）          起止时间（右）
  · 工作要点1
  · 工作要点2

  [项目名] [角色标签badge]          项目时间
    **项目背景**：...
    **核心动作**：...
    **项目成果**：...
```

视觉层级：公司 > 项目 > 正文

- 公司行：14-15px 加粗
- 项目名：13px 加粗
- 正文：12-13px 常规

## 个人简介样式

```
浅色底色块(#F5F6FA) + 左侧 3px 主色竖条
正文两端对齐
```

## 技能标签样式

```
浅色底色的行内标签（badge）
圆角 3px，padding 2px 8px
背景 #F0F2F5，文字 #333
```

## 角色标签

```
项目名右侧的浅色底小标签
圆角 3px，padding 1px 6px
背景 #E8ECF0，文字 #555，12px
```

## 列表样式

```css
列表要点统一使用细圆点符号（CSS ::before 实现）
不混用不同符号
要点间距 4-6px
```

## 禁止元素

- 照片、图标、进度条、雷达图
- 表格布局、文本框、绝对定位
- 外部字体/图片/CDN 资源

确保内容可复制、ATS（简历解析系统）可解析。

## 链接处理

- 邮箱：`mailto:` 链接
- 作品集/GitHub：可点击超链接
- 链接文字用主色，无下划线（hover 时显示下划线）

## 可选风格

| 风格 | 说明 |
|------|------|
| 商务稳重（默认） | 黑白灰为主，深蓝点缀 |
| 互联网感 | 浅色色块区分模块，仍保持单栏 |
| 极简主义 | 无色块无分隔线，靠字号字重和留白区分层级 |
| 双栏（不投 ATS） | 左窄栏联系方式/技能/教育，右宽栏经历/项目 |

默认使用"商务稳重"。用户可在生成时指定风格。
