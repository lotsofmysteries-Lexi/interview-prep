# HR回复话术模板库

## 风格指南

**总基调**：理性冷静，简短直接，可一键复制使用。

**风格示例**：
- ✅ "团队目前几个人？"
- ✅ "这个岗位汇报给谁？"
- ✅ "试用期多久？通过标准是什么？"
- ❌ "请问贵司该岗位之组织架构及人员配置情况为何？"（太公文）
- ❌ "宝子们这个岗位一定要问清楚团队配置哦！"（太随意）

**核心原则**：
1. 短句，一句只问一件事
2. 去掉所有修饰词和连接词
3. 不用"您/贵司/请问/想了解一下"等缓冲语
4. 直接问，不解释为什么问
5. 问题自带回答格式指引（Y/N/数字/选项）

## 话术风格变体（新增）

根据用户偏好，同一意图可以有三种表达方式：

### 风格A：温和进取型（默认）

**特征**：正面表达优势，坦诚提及缺口，不过度推销也不过度保留

| 场景 | 话术示例 |
|------|---------|
| 背景介绍 | "我过去两年专注AI Agent产品落地，主导过从0-1的智能化项目。想了解一下..." |
| 技术缺口 | "我在之前的工作中主要接触的是LLM应用层，虽然技术栈不同，但在模型性能调优的方法论上有共通之处。" |
| 优势表达 | "主导过AI Agent从0-1的落地，在复杂业务建模和Agentic Workflow编排上有一些实践。" |
| 工作方式 | "我比较擅长深度技术问题分析和系统性方案设计，想了解一下这个岗位的日常工作中深度攻坚和客户支持各自的占比。" |

### 风格B：激进推销型

**特征**：主动将差异化背景包装为核心竞争力，强调独特价值

| 场景 | 话术示例 |
|------|---------|
| 背景介绍 | "我的跨学科背景让我能从系统视角理解技术问题，这是纯技术出身同学少有的优势。" |
| 技术缺口 | "虽然技术栈有差异，但我快速学习新领域的能力已经被多次验证——从建筑到AI产品的转型就是例子。" |
| 优势表达 | "我可能是这个岗位能找到的少有的既有产品落地经验、又懂复杂系统建模的候选人。" |
| 工作方式 | "我在高压环境下反而能激发更好的表现，之前多个0-1项目都是在时间紧迫的情况下交付的。" |

### 风格C：低调试探型

**特征**：淡化背景差异，聚焦能力匹配，避免过度暴露

| 场景 | 话术示例 |
|------|---------|
| 背景介绍 | "我在AI应用落地方面有一些实践，想了解一下这个岗位对技术深度的期待。" |
| 技术缺口 | "想了解一下团队对新人的技术培养机制，特别是在底层优化方面的学习曲线。" |
| 优势表达 | "比较擅长深度技术问题分析和系统性方案设计。" |
| 工作方式 | "想了解一下这个岗位的日常工作中，深度技术攻坚和客户支持各自的占比大概是怎样的？" |

### 背景淡化策略（新增）

**原则**：不主动提及转行/非科班背景，被问及时用以下策略回应

| 触发场景 | 回应策略 | 示例 |
|---------|---------|------|
| 主动介绍背景时 | 聚焦能力，模糊路径 | "我在AI产品落地方面有两年实践，主导过Agent从0-1的项目" |
| 被问及专业背景时 | 一句话带过，立即转向能力 | "我本科是建筑学，后来转向AI产品方向，在复杂系统建模上反而有一些跨领域的视角" |
| 被问及技术深度时 | 承认差距但强调方法论迁移 | "底层优化接触不多，但在应用层性能调优上有一些经验，方法论上应该可以迁移" |
| 需要解释转型动机时 | 用"系统思维""复杂问题"等抽象概念包装 | "发现自己更享受抽象建模和逻辑推演，所以转向了更匹配这个偏好的方向" |

## 信息缺口分类与对应话术

### 缺口类型A：团队配置

**触发条件**：JD未说明团队规模、汇报关系、协作角色

**话术模板（一键复制版）**：

```
想了解下团队目前有几个人？
这个岗位向谁汇报？
日常主要跟哪些角色配合？
```

---

### 缺口类型B：工作内容边界

**触发条件**：JD描述模糊，职责范围不清晰

**话术模板（一键复制版）**：

```
日常工作内容大概分哪几块？
从0-1和迭代优化各占多少？
需要直接面对客户吗？
```

---

### 缺口类型C：考核方式（KPI/OKR）

**触发条件**：JD未说明如何衡量绩效

**话术模板（一键复制版）**：

```
试用期多久？通过标准大概是什么样的？
绩效多久评一次？看哪些指标？
```

---

### 缺口类型D：薪资结构

**触发条件**：JD未说明薪资细节或只给了宽泛范围

**话术模板（一键复制版）**：

```
这个薪资是base还是总包？
年终奖一般几个月？跟什么挂钩？
有期权吗？
```

---

### 缺口类型E：职业发展路径

**触发条件**：JD未说明晋升通道和发展空间

**话术模板（一键复制版）**：

```
这个岗位的晋升路径大概是什么样的？
接下来一年团队有扩编计划吗？
做得好的同事后续一般往哪发展？
```

### 缺口类型F：技术栈和工作方式

**触发条件**：技术工具链、开发流程、工作模式不明确

**话术模板（一键复制版）**：

```
工作模式是怎样的？可以远程吗？
团队加班多吗？
有出差需求吗？
```

## HR回避应对策略

当HR回避某个问题时：

1. 换个角度再问
2. 缩小范围降低威胁感
3. 标记为"高风险信息缺口"，在最终建议中提醒用户注意
