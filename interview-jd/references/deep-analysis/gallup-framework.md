|:-----|:-----|:---------|

| 信仰 | Belief | 持久的核心价值观指引方向 |
| 公平 | Consistency | 坚信公平对待，重视规则和程序 |
| 审慎 | Deliberative | 谨慎评估风险，预见障碍 |
| 纪律 | Discipline | 享受常规和结构，创建可预期的流程 |
| 专注 | Focus | 确定优先事项并保持方向 |
| 责任 | Responsibility | 对承诺承担义务，不让人失望 |
| 排难 | Restorative | 乐于发现问题并修复 |

## 在job-analyzer中的应用方式

### 不是给用户做测试

不需要用户完成34项完整测评。而是：

1. **从岗位需求反推**：这个岗位需要哪些领域的才干偏强？
2. **从用户行为推断**：基于已有Profile字段，用户大概在哪个领域偏强
3. **找张力点**：岗位需要的才干领域 vs 用户偏好领域不一致 → 标注"能量消耗点"

### 常见岗位类型与才干领域对应

| 岗位类型 | 核心才干领域 | 辅助领域 |
|:---------|:-----------|:---------|
| AI产品经理 | 战略思维 + 执行力 | 影响力（推动落地） |
| 解决方案架构师 | 战略思维 + 影响力 | 关系建立（客户信任） |
| 技术运营/使能 | 执行力 + 战略思维 | 关系建立（开发者社区） |
| 咨询顾问 | 影响力 + 战略思维 | 关系建立 |
| 研究型PM | 战略思维 | 执行力 |
| 交付型PM | 执行力 + 关系建立 | 影响力 |

### 张力点识别示例

**岗位需要"影响力"但用户偏好"战略思维"**：
- 岗位要求：频繁对客户宣讲方案、推动决策
- 用户偏好：更习惯内部思考、分析框架
- 能量消耗：每次客户宣讲都是放电，需要预留恢复时间

**岗位需要"执行力·纪律"但用户偏好"关系建立·适应"**：
- 岗位要求：按严格流程推进项目、定期汇报
- 用户偏好：灵活应变、根据人际动态调整
- 能量消耗：被流程约束感消耗，需要在灵活空间中恢复

## 盖洛普核心理念在求职分析中的映射

> "职业决策变得更容易，当你少关注'什么'职业最适合你，而更多关注'为什么'和'怎么做'。"

| 传统思路 | 优势导向思路 |
|:---------|:-----------|
| 什么职业适合我（标题匹配） | 为什么某个角色适合你（动机匹配） |
| 我的技能匹配哪些岗位 | 我如何最佳工作（方式匹配） |
| 补短板 | 用优势、避消耗 |
| 简历关键词 vs JD关键词 | 人格特质 vs 工作方式 |
